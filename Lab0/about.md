Ответы на вопросы по Git



1.Что такое Git и для чего он используется?

Git — это система контроля версий для отслеживания изменений в файлах и совместной работы над кодом.

2\. В чём разница между централизованными и распределёнными системами контроля версий?

В централизованных системах вся история хранится на одном сервере. В распределённых (как Git) копия истории хранится у каждого разработчика локально.



3.Что такое репозиторий в Git?

Репозиторий — это папка проекта, за изменениями в которой следит Git.
